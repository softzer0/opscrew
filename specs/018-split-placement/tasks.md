# Tasks: Split placement and the private network

**Input**: `specs/018-split-placement/`:
- spec.md, plan.md, research.md (R1–R7 and the spikes R5a, R5b, R6a), data-model.md;
- contracts/split-placement.md, quickstart.md;

plus `docs/adr/0022-split-placement-and-private-network.md`, and features 000–017.

**Numbering**: T1801–T1899.

**Format**: `- [ ] T#### [P] [USn] description` + `Owns / Reads / Depends / Accept / Verify /
Effort`.

**Rules for every task:**
- **Fixtures** never contain secret-shaped literals. Use `fakeSecret()`, or `{{FAKE:…}}` with
  `materializeFixture()`. WireGuard keys in tests come from the injected key maker, never literals.
- **No network:** no test touches the network, a real cloud, a real GitHub or a model. Tests that
  need Docker, `ssh`, `wg` or other tools skip with a clear message when the tool is absent.
- **No leaks:** none of these may appear in a plan, a host plan's text, a committed or generated
  file, a log, an audit entry, a report, a snapshot or an MCP response (SC-1807):
  - a WireGuard private key;
  - a device login's password, or the root password used to make it;
  - an app secret;
  - a server's public address, in anything committed.

  Every task's tests include a leak check for the values it handles.
- **Approvals:** every change goes through its plan, approved by its hash: `iac-apply` for cloud
  resources, `host-apply` for each server, `pull-request` and `github-secrets` for the repository.
  Deleting a server or an old copy needs `allowDestroy` and a typed name. No new approval kind.
- **Untouched unless used:** a plan with no `servers` and no `network` renders byte-identical files
  (snapshots) and runs the same commands as before. That covers every target.
- **Server names in output:** every line about a server names it (`app` or the extra server's
  name). Addresses are masked as everywhere else.
- **Scope:** build only what Accept asks. Report anything else as a finding.
- **Writing files:** write long files with the Write or Edit tool, not shell heredocs (Windows
  Defender blocks some).
- **Neutral examples only:** `example.com`, `example-app`, `203.0.113.0/24` for public addresses,
  and `10.200.4.0/24` for a private network.
